O organograma abaixo representa a estrutura da equipe responsável pelo desenvolvimento do Sistema de Gerenciamento de Colaboradores AstroTech. A equipe é composta por três membros, cada um com papéis específicos para garantir o sucesso do projeto. Este organograma é fictício e foi criado para ilustrar a organização do time.

Observações

A estrutura é simplificada devido ao tamanho reduzido da equipe.
Os papéis foram atribuídos com base em uma divisão lógica de tarefas para um projeto web.
Para projetos futuros, a equipe pode ser expandida com roles como Designer UX/UI, Analista de Qualidade (QA) ou DevOps.
